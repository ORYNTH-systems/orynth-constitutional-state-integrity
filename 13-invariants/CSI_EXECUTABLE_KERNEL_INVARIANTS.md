# CSI Executable Kernel Invariants — Batch 06

CSI-EXE-INV-001
Every executable constitutional source dependency resolves through a registered
source anchor.

CSI-EXE-INV-002
A source anchor is invalid if its authoritative source hash no longer matches
the admitted source snapshot.

CSI-EXE-INV-003
Jurisdiction is operation-specific.

CSI-EXE-INV-004
Actor class alone does not authorize an operation outside its registered scope.

CSI-EXE-INV-005
Delegation cannot authorize an operation absent from the principal's own scope.

CSI-EXE-INV-006
Autonomous agents possess no constitutional authority by capability alone.

CSI-EXE-INV-007
Unresolved predicates remain non-executable for consequential transition.

CSI-EXE-INV-008
Conflicted evidence remains non-executable for consequential transition.

CSI-EXE-INV-009
Deterministic relevance traverses both upstream and downstream dependencies.

CSI-EXE-INV-010
Deterministic relevance traversal never returns alteration authority.

CSI-EXE-INV-011
All consequential execution requires valid source, predicate, jurisdiction,
authority, and evidence states.

CSI-EXE-INV-012
Correctness of a proposed outcome cannot substitute for execution authority.
