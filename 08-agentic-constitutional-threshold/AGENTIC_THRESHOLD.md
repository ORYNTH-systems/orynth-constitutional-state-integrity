# Agentic Constitutional Threshold

The introduction of autonomous or semi-autonomous agents changes the execution
environment.

It does not modify constitutional source.

Constitutional constraints remain applicable to execution regardless of
whether an operation is performed by:

- a human;
- software;
- an autonomous agent;
- multiple agents;
- a delegated system;
- a hybrid human-agent system.

The executor is variable.

The constitutional source is not.
