# Scope and Non-Scope

## In Scope

- canonical constitutional source mapping
- constitutional object typing
- authority lineage
- jurisdiction
- constitutional predicates
- predicate dependency
- predicate equivalence and conflict
- evidence provenance
- deterministic relevance
- inherited-state analysis
- agentic constitutional application
- UAA integration
- Voter Integrity Protocol integration
- constitutional execution traceability

## Out of Scope

CSI does not itself:

- amend the United States Constitution;
- create new constitutional powers;
- create new constitutional rights by software assertion;
- assign authority merely because an actor has execution capability;
- convert political preference into constitutional authority;
- automatically alter historical states merely because they become relevant.
