# Constitutional Source-to-Execution Boundary

The source chain is:

U.S. CONSTITUTION
    ↓
CANONICAL SOURCE OBJECT
    ↓
STRUCTURAL UNIT
    ↓
CONSTITUTIONAL OBJECT
    ↓
PREDICATE
    ↓
DEPENDENCY
    ↓
JURISDICTION
    ↓
AUTHORITY
    ↓
ORYNTH APPLICATION
    ↓
UAA AUTHORIZATION
    ↓
DOMAIN PROTOCOL
    ↓
CONSEQUENTIAL EXECUTION

The source layer SHALL terminate before interpretive or execution authority
is introduced.

No downstream state may mutate the upstream constitutional source.

Human, agentic, and hybrid execution environments consume constitutional
constraints through ORYNTH application mappings.

They do not create or rewrite those constraints.
