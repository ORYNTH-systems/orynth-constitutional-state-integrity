# CSI Adversarial Verification — Batch 08

The verifier must fail or block when any of the following occurs:

1. constitutional source hash changes;
2. required proof surface is missing;
3. predicate TRUE/FALSE collision is introduced;
4. authority VALID/INVALID collision is introduced;
5. required execution dependency is absent;
6. inherited state remains unresolved;
7. predicate equivalence remains unresolved where identity is required;
8. execution provenance is absent;
9. source and destination collapse during transformation;
10. agentic capability is substituted for authority;
11. deterministic relevance is substituted for reversal authority;
12. finality is used to discard provenance.

The verifier is intended to detect architectural corruption, not determine
substantive constitutional doctrine.
