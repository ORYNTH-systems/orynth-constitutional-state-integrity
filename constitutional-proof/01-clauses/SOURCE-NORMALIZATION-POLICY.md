# SOURCE NORMALIZATION POLICY

status: ACTIVE

## Fundamental Separation

RAW SOURCE != NORMALIZED ADJUDICATION VIEW

The frozen Batch 04A candidate corpus remains immutable.

Normalization creates a derived representation and never destroys raw provenance.

## Permitted N1R Transformation

Only the publication running header:

C O N S T I T U T I O N O F T H E U N I T E D S T A T E S

is removed.

## Artifact-Only Candidate Rule

If removal of the publication running header leaves no constitutional text, the raw candidate remains in provenance but is classified EXCLUDED-PUBLICATION-ARTIFACT and EXCLUDED-NONSEMANTIC for adjudication.

Exclusion is not deletion.

## Embedded Header Rule

If constitutional text remains after removal of a running header, the derived candidate remains ELIGIBLE for boundary adjudication.

## Deferred Transformations

This batch does not:

- dehyphenate line-wrapped words
- remove editorial brackets
- remove footnote or amendment markers
- modernize spelling
- correct punctuation
- paraphrase constitutional language
- derive constitutional mechanisms
- derive predicates
- reference ORYNTH architecture

## Provenance

Every derived row retains both raw and normalized SHA256 values.

Every transformation is recorded in SOURCE-NORMALIZATION-LEDGER.csv.
